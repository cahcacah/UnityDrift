# UnityDrift

UnityDrift enables real-time, auto-scaling data processing across cross-platform systems via a centralized manager.

With UnityDrift, you get a lightweight tool that stays out of your way.

**What you get**

- UnityDrift enables real-time, auto-scaling data
- processing across cross-platform systems via
- a centralized manager

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/UnityDrift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure UnityDrift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
